# Lead registry

Create one JSON file per lead with these fields: `lead_id`, `source`,
`observation`, `evidence`, `affected_phase_shapes`, `wall_clock_share`,
`amdahl_ceiling`, `suspected_mechanism`, `cheapest_falsifier`,
`correctness_risk`, `implementation_cost`, `priority` (`P0` through `P4`), and
`status`. A lead is an anomaly or opportunity, not an optimization claim.
